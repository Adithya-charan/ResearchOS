# Nitrogen fixation in legume rotations

Abstract

Legumes host bacteria that fix nitrogen. We estimated the nitrogen left for the next crop after a legume rotation.

Methods

Plots grew clover, peas or barley for one season. Soil nitrogen was measured the following spring, and nodules were counted on legume roots.

Results

Plots that grew clover held 30 kilograms per hectare more nitrogen than plots that grew barley. Pea plots fell in between, with fewer nodules per plant.
